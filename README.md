# Football News Website

A responsive football news website featuring football updates, transfer news, club rankings, and individual news articles. Built using HTML, CSS, JavaScript, and Bootstrap.

## Features

- **Football News:** Browse football-related news and updates.
- **Transfer News:** Read about player transfers and transfer rumours.
- **Club Rankings:** Explore football club rankings.
- **User Login:** Simple demo login and logout functionality.
- **Responsive Design:** Layout adapted for desktop and mobile screens.
- **Article Pages:** Dedicated pages for individual football stories.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Google Fonts (Inter)
- Browser Local Storage

## Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ashwinmuralinair2002/fabrom-login.git
   ```

2. Navigate into the project:

   ```bash
   cd fabrom-login/docs
   ```

3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open the following address in your browser:

   ```text
   http://localhost:8000
   ```
